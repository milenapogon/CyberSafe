# CyberSafe

### Aplikacja edukacyjna z zakresu cyberbezpieczeństwa

## Opis projektu

CyberSafe to aplikacja internetowa tworzona w ramach projektu semestralnego na kierunku Informatyka. Jej celem jest zwiększanie świadomości użytkowników w zakresie cyberbezpieczeństwa oraz promowanie bezpiecznych nawyków podczas korzystania z Internetu.

Aplikacja będzie składać się z dwóch głównych modułów:

**1. Password Lab**
- Generowanie losowych haseł.
- Wybór długości i rodzaju znaków.
- Analiza siły hasła.
- Wskazówki dotyczące tworzenia bezpiecznych haseł.

**2. Security Quiz**
- Pytania dotyczące cyberbezpieczeństwa.
- Wybór odpowiedzi i automatyczne sprawdzanie poprawności.
- Naliczanie punktów i prezentacja końcowego wyniku.

## Wykorzystane technologie

- HTML5 – struktura aplikacji.
- CSS3 – wygląd i styl interfejsu.
- JavaScript – logika i funkcjonalności.
- Web Crypto API – bezpieczne generowanie danych losowych.
- localStorage – lokalne przechowywanie danych.
- Git i GitHub – kontrola wersji i przechowywanie kodu.

## Uruchomienie projektu

1. Pobierz repozytorium na komputer.
2. Otwórz folder projektu w Visual Studio Code.
3. Otwórz plik `index.html`.
4. Uruchom aplikację za pomocą rozszerzenia Live Server.

## Status projektu

Projekt znajduje się w trakcie realizacji. Przygotowano podstawowy interfejs użytkownika, strukturę aplikacji oraz nawigację pomiędzy modułami. Kolejnym etapem jest implementacja generatora haseł i quizu.
